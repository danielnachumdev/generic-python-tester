# huji-oop-stdio-tester

Python stdin/stdout test harness for HUJI **OOP (Java)** exercises (`danielutils` `TestFactory`).

Edit the `FILES` table in `main.py`, then:

```bash
python main.py
```

First run may create `./venv` and install `danielutils`. Aimed at Windows/macOS.
